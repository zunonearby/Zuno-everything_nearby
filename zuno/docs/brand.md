# Brand

**ZUNO — Everything nearby.**

## Colors

| Token      | Hex       | Use                                   |
|------------|-----------|----------------------------------------|
| Primary    | `#0F5D3A` | Deep green — primary brand color       |
| Secondary  | `#22A06B` | Supporting green                       |
| Accent     | `#A7D56B` | Lime accent                            |
| Background | `#F8FAF6` | Warm off-white app background          |
| Surface    | `#FFFFFF` | Cards / surfaces                       |
| Text       | `#17231D` | Primary text                           |

Direction: modern, premium, clean, minimal, trustworthy, local, fresh,
technology-driven. **Category-neutral** — not every UI element should be
green.

Category-specific accents (grocery, fast food, pharmacy, ...) are
secondary and defined in `packages/config/src/categoryColors.ts`. They
decorate category-specific UI (badges, icons) — they never replace the
primary palette across the whole app.

## Logo

The provided ZUNO wordmark (leaf + location-pin "Z" mark) is the source
of truth and has not been redesigned. See `assets/brand/README.md` for
available variants.
